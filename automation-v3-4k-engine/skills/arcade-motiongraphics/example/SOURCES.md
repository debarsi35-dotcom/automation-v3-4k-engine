# Sources: "How Mario was born" (Arcade Motion Graphics demo, 2026-10-26)

## Facts (each checked against two sources)
| claim in the film | sources |
|---|---|
| 1981: Nintendo of America stuck with ~2,000 unsold Radar Scope cabinets; Donkey Kong was designed so they could be converted | Wikipedia "Radar Scope" + "Donkey Kong"; StrategyWiki "Radar Scope" (sales figures vary: ~3,000 shipped, ~1,000 sold; ~2,000 converted) |
| Shigeru Miyamoto designed the new game | Wikipedia "Donkey Kong", "Mario" |
| Mario drawn on a 16×16 pixel grid in Donkey Kong | Wikipedia "Mario" ("drawn using pixel dots in a 16x16 grid") |
| Cap = avoid drawing hair; moustache = no mouth needed | Wikipedia "Mario"; Nintendo-sourced interviews quoted by the Jakarta Post / Gulf News 30th-anniversary pieces |
| Called "Jumpman" (English instructions), renamed after landlord Mario Segale | Wikipedia "Mario"; Technologizer "The True Face of Mario" (2010); KIRO7 |
| Super Mario Bros. (1985) sold over 40 million copies | Guinness World Records (40.24 M as of 2013); Wikipedia best-selling NES games |
| Mario = best-selling video game series ever | Wikipedia "Mario" / list of best-selling video game franchises |
| 256 pixels | 16 × 16 = 256 |

Not used on purpose: the "angry landlord demanding back rent" anecdote (disputed by Don James and Technologizer).
